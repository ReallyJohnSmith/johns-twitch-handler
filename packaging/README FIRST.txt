JOHN'S TWITCH HANDLER TESTER VERSION
Release: Tester

START HERE

Open "Tester kit", then "START HERE.html" for the step-by-step guide.
It opens in your browser and can be read without internet access.
You can also find "Tester guide" inside the app's Settings.

You do not need to be technical, install programming tools, or go live to try it.
If you get stuck, stop there and tell John what happened.

GETTING STARTED

1. Open the downloaded Setup file while you are not streaming or recording.
2. It opens the dashboard in your browser and adds Desktop and Start Menu shortcuts.
3. Follow the guide to connect OBS. Twitch and the other services are optional.
4. Try the short off-stream checklist, then reply privately to John's invitation.

Leave any service you do not use set to No. You should not need developer IDs,
access tokens, or stream keys. If something asks for those, check with John first.

UPDATES AND CLOSING

Open a newer Setup file only between streams. Updates are designed to keep your
saved connections, settings, and reports. There is no automatic updater yet.
Closing the browser tab leaves the app running; the Desktop shortcut restarts it.
Ask John for help removing the app. There is no uninstall button yet.

PRIVACY

Settings and reports stay on your PC. John does not receive them automatically.
Connected services receive the requests needed for their features.
Never send passwords, sign-in codes, stream keys, private chat, or viewer notes.
Check screenshots before sharing them. Treat GitHub reports as public.

WINDOWS MAY ASK FOR CONFIRMATION

This test installer is not signed. If a warning worries you, stop and ask John.
Do not turn off Windows protection or your antivirus.

NEED HELP

A private message saying what you clicked and what happened is enough to start.
Include the version near the app name, or say "not sure" if it will not open.

If John asks for a troubleshooting file, open Settings, then "Connection help
and recent log", then "Export safe diagnostic report". Send only that downloaded
file privately to John. Do not post it on GitHub or send whole app/log folders.
