JOHN'S TWITCH HANDLER TESTER VERSION
Release: Tester

START HERE

1. Open the downloaded John's Twitch Handler Setup application.
2. It creates Desktop and Start Menu shortcuts for you.
3. The setup screen opens automatically in your browser.
4. For a future update, download and open the newer Setup application.

SETUP

1. Open OBS.
2. In OBS, open Tools, then WebSocket Server Settings.
3. Copy the WebSocket password into the Handler and click Connect OBS.
4. Click Connect with Twitch and approve access in your browser.
5. Leave Spotify, Tangia, StreamElements, or TikFinity set to No if you do not use them.

OPTIONAL FEATURES

- Paste a current YouTube livestream URL to display its official chat beside Twitch. No Google login
  is requested. Automated messages remain Twitch-only.
- Safe automations, recurring Twitch reminders, raid history, layouts, and preferences stay on your
  computer. Automations cannot run scripts or external programs.
- StreamElements multistream planning is available if you install SE.Live. Stream keys and account
  sign-ins remain inside OBS and StreamElements.
- TikFinity can add read-only TikTok chat when its separate desktop app is open. It defaults to No,
  requests no TikTok login in the Handler, and stores no TikTok credentials.
- Preflight includes a manual Get Coffee reminder. Add or remove your own reminders, and use Open
  preflight list to hide built-in rows you do not want to see. Hiding affects visibility only.
- Prefer Simple mode but need one detailed tool? Switch to Advanced, press Add to Simple on that
  panel, then return to Simple. The chosen tool appears there without exposing every Advanced panel.

You do not need .NET, Node.js, a database, a Twitch developer app, or a Spotify developer app.
Your Twitch and OBS connections are encrypted for your Windows account and stay on your computer.

PRIVACY

John cannot see anything you enter in the Handler. The package contains no saved passwords, access
tokens, stream reports, viewer notes, or personal connection data. Preferences, reports, and
connection history stay on your computer, and credentials are encrypted for your Windows account.
Nothing is remotely stored by John. He receives diagnostic information only if you export the safe
report and personally choose to send it to him.

WINDOWS MAY ASK FOR CONFIRMATION

This personal test build is not code-signed. Only open it if John sent it to you and you trust it.

NEED HELP

Open Settings, expand "Connection help and recent log", and click "Export safe diagnostic report".
Send that JSON file to John. It does not contain passwords, access tokens, channel IDs, or OBS URLs.
