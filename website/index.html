A FEW THINGS TO KNOW

Before you jump in.

No developer tools needed to explore or use a supplied installer.

Can I look around before installing?

Yes. Open the interactive demo. It uses made-up session data and never connects to your helper, OBS, or an account.

Is this a website or a Windows app?

The full product is a Windows app with a browser dashboard. A website-connected version also uses a Windows helper for OBS, PC monitoring, and local files. The interactive demo runs on this website by itself.

Does it monitor my internet connection?

The running Windows app checks connection responsiveness and records notable interruptions. It checks response times, rather than measuring your maximum upload speed. Its background checks can continue when you close the dashboard tab.

Where do my connections and reports go?

The installed Handler stores account connections and session reports on your PC. Account credentials are encrypted for your Windows account. The website demo uses sample data and sends no feedback or account information.

Do I need to connect every service?

No. Start with the demo, then OBS if you want to try stream controls. Connect your own Twitch account when you want its features. Spotify, Tangia, StreamElements, and TikFinity are optional.

What if I downloaded a source-code ZIP?

For the normal tester setup, you need the supplied file ending in Setup.exe. A source-code ZIP is for development. Ask John for the installer if you don’t see one.
