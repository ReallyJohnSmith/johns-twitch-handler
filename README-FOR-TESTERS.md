# Trying John's Twitch Handler

Thanks for taking a look. You do not need to write code, install developer tools,
or connect every account. Start with whatever feels useful to you.

## 1. Get the Windows app

For the full app, you need a **64-bit Windows PC**. Use the same PC as OBS.

1. Use the **Setup.exe** installer John supplied or the release named in your
   invitation. If you do not have an installer, ask John for it.
2. Run it while you are **not streaming or recording**.
3. The Handler opens in your browser. You can reopen it later from the
   **John's Twitch Handler** Desktop or Start Menu shortcut.

A source-code ZIP is for development. For this test, use the installer ending in
**Setup.exe**. If Windows displays a warning you do not understand, ask John;
you do not need to turn off Windows protection.

## 2. Look around first — about two minutes

Open the Handler and explore **Pre-stream**, **During stream**, and **After
stream**. You can close Settings and look at the layout before connecting accounts.

The clearly labeled guided-demo panel uses sample data. Other controls operate
your real setup, so keep streaming and recording stopped while exploring.

## 3. Try a small first test — about five minutes

- Read **Pre-stream**. Can you tell what is ready and what needs attention?
- Open **Appearance** and choose a style or color you like.
- Try **Simple** and **Advanced** modes. Which feels easier to understand?
- If you want to try real scene controls, connect OBS using the steps below.
- Close and reopen the dashboard. Did your saved choices remain?

To connect OBS, open **Tools → WebSocket Server Settings** in OBS. Enable the
server, keep authentication enabled, and use **Show Connect Info** to find its
password. In the Handler's **Settings**, paste that password into the OBS
password box and select **Connect OBS**. Leave the default address alone.

With streaming and recording stopped, note your current OBS scene, select a
different one in the Handler, then return to the original scene.

The installed app's controls affect your real setup. Only the clearly labeled
guided-demo panel uses sample data. There is no need to go
live, run ads, create clips, or change OBS quality settings for this first test.

## Optional connections

Connect your own Twitch account when you want to try Twitch features. Spotify,
Tangia, StreamElements, and TikFinity can stay off. If a connection asks for
developer IDs or tokens you do not have, skip it and tell John.

Reply privately to the message where John invited you. A plain message is enough;
you do not need a GitHub account or technical vocabulary.


“Not sure” is a useful answer. Keep passwords, sign-in codes, stream keys,
private chat, and account tokens out of feedback and screenshots.

Need more detail? Use the [full tester guide](docs/tester-kit/README.md), or ask
