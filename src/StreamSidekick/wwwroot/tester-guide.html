1. Get your copy

You need a 64-bit Windows PC and a browser. Use the same PC as OBS. Internet access is needed for downloading and connecting accounts. No programming tools are needed.

  1. Open the download page and choose the release John asked you to test.
  2. Under Assets, the list of downloads, choose the file ending in Setup.exe. Ignore the source-code ZIP files.
  3. If no Setup file is listed or you cannot access the page, ask John for a download.
  4. While you are not streaming or recording, open the downloaded Setup file. It opens the app in your browser and adds Desktop and Start Menu shortcuts.

Windows may warn about an unrecognized app because this test installer is not signed. If you are unsure, stop and ask John. Do not turn off Windows protection or your antivirus.

Already installed? Open John's Twitch Handler from the Desktop or Start Menu. Its browser window is normal: the app runs on your PC.

2. Connect OBS

Leave streaming and recording stopped for your first test.

  1. Open OBS, then choose Tools → WebSocket Server Settings. This lets the Handler talk to OBS on your PC.
  2. Turn on Enable WebSocket server and keep Enable Authentication turned on.
  3. Choose Show Connect Info and copy the Server Password. Keep it private.
  4. In the Handler, open Settings. Paste the password into the OBS Password box, then choose Connect OBS.

Leave the advanced address setting alone. If you cannot find the menu or connect, ask John; you do not need to change router or firewall settings.

Twitch and other tools are optional

For Twitch features, choose Connect with Twitch. Review the sign-in and permission screen for your own account, and approve only if you are comfortable. Handle sign-in checks yourself. You can skip this and still try the guided demo and appearance settings.

Leave Spotify, Tangia, StreamElements, and TikFinity set to No unless you use them. You should not need developer IDs, access tokens, or stream keys. If the normal connection asks for them, stop and tell John.

3. Try the basics — about 10 minutes

Try this off-stream and not recording. Tick what you try. These ticks are just for you, are not saved, and do not send anything to John. You can print this page from your browser.

Only the guided-demo panel uses sample data. Other controls still affect your real OBS or Twitch account. You do not need to go live, record, send chat messages, run ads, raid anyone, or change OBS quality settings for this test.

Save replay files, clips, highlight markers, and real stream reports for a later planned test with John. A demo does not create a real stream report.

If John asks for a troubleshooting file

In Settings, open Connection help and recent log → Export safe diagnostic report. Send that one downloaded file privately to John, not to a public GitHub report. The export is designed to omit passwords and tokens; ask before sharing if you are unsure. Do not send whole app or log folders. If the app will not open, the error message is enough to start.

Help and a few limits

  • Cannot open the app? Tell John what appeared. A cropped screenshot of the error helps.
  • OBS will not connect? Check that it is open and that you used its Server Password, not your Twitch password.
  • Missing a feature? The last approved release is .015. Tactical Console, new Broadcast/Ocean/RPG defaults, Reset layout, and FPS tools are waiting for the next numbered release. Skip anything missing in your build. This kit does not confirm a new installer is published.
  • Want your panels back? If available, Reset layout restores their arrangement after confirmation. It keeps your connections and appearance choices.
  • Need an update? There is no automatic updater yet. Open the newer Setup file John shares, between streams. Updates are designed to keep your settings and reports.
  • Closing the tab does not stop the app. The Desktop shortcut restarts it. While it is already running, open just the dashboard to avoid a restart.
  • Want to remove it? Ask John for help. There is no uninstall button yet. Removing a shortcut does not remove the app or saved data.
  • Some tools need extra setup. Replay saves need OBS Replay Buffer running. Spotify playback needs Premium. Twitch features depend on your channel permissions. WoW addon tools are currently paused.
  • Your data stays on your PC. Settings and reports are not sent to John automatically. Connected services still receive the requests needed for their features.
