# John's Twitch Handler .016 — tester preview

Download **Johns-Twitch-Handler-Tester-v016-Setup.exe** from this release's
Assets. Run it on a 64-bit Windows PC while streaming and recording are stopped.
The installer opens the dashboard and adds Desktop and Start Menu shortcuts.
Windows may show a warning because this preview is unsigned; ask John if unsure.

Start with the installed **Tester kit/START HERE.html**, or open **Settings →
Tester guide**. Try OBS scene controls, appearance choices, and Simple/Advanced
mode off-stream first. Twitch and the other connections are optional. Settings
and reports stay on your PC; updates are designed to retain them.

This version includes simpler first-run setup, startup retry, clearer connection
and health feedback, a clean Twitch message list, Tactical Console, Reset layout,
FPS/RPG profiles, and the offline tester guide. It also reduces repeated requests
and suspends dashboard polling while the browser tab is hidden.

The first test does not require going live. Reply privately to John's invitation
with your version, what you tried, and what happened. Keep passwords, stream
keys, sign-in codes, private chat, and unedited logs out of feedback.
