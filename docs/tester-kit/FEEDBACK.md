# Tell me how it went

[Back to the guide](README.md)

You do not need technical terms or a GitHub account. Reply privately to John's invitation and describe what happened in your own words. If you are unsure about a detail, write “not sure.”

## A message you can copy

```text
I tried John's Twitch Handler.

App version (near the app name):
What I was trying to do:
What I clicked, in order:
What I expected:
What happened instead (include any error words):
Did it happen again, or just once?
Was I offline, recording, or live?

Windows version, if I know it:
OBS version, if I know it:

What confused me:
What worked well:
What would make me use this regularly:
```

If you want to check, Windows shows its version under **Start → Settings → System → About**. OBS shows its version under **Help → About**. You can skip these if you cannot find them.

## Prefer GitHub?

GitHub requires an account to submit a report. Use [Report a problem](https://github.com/ReallyJohnSmith/johns-twitch-handler/issues/new?template=problem.yml) or [Share your experience](https://github.com/ReallyJohnSmith/johns-twitch-handler/issues/new?template=feedback.yml). These forms become available when this kit is published to the repository. If they do not open, send John a private message instead.

Treat GitHub reports as public. Never post passwords, sign-in codes, stream keys, access tokens, private chat, viewer notes, or unedited logs. Check screenshots for those details before sharing them.

## If John asks for a diagnostic report

This is optional. It is a small troubleshooting file, not something you need to understand.

1. Open the Handler's **Settings**.
2. Expand **Connection help and recent log**.
3. Choose **Export safe diagnostic report**. Your browser downloads a file.
4. Send that one file **privately** to John through the same conversation where you were invited. Do not attach it to a public GitHub report.

The export is designed to leave out passwords and sign-in tokens. If you are unsure what is in it, ask John before sharing. Do not send your whole app folder, session reports, or Windows user folder. If the app will not open, just send the error message first.

If you think you found a privacy or security problem, contact John privately instead of opening a public report.
