# A few things to know

[Back to the guide](README.md)

This is a test build. Please use it off-stream first, and keep your usual OBS controls available when you later try it live.

## Which version am I testing?

Look for **Version** near the app name. Include that number in feedback. The last approved version is **.015**; this kit does not announce a newer release or confirm that an installer has been uploaded.

The GitHub source can describe work that is not in your installed copy yet. Tactical Console, the new Broadcast/Ocean/RPG defaults, Reset layout, and FPS kill/death tools are listed under **Unreleased** in the [release notes](https://github.com/ReallyJohnSmith/johns-twitch-handler/blob/main/CHANGELOG.md). Skip checklist items that are not in your build. Their absence in .015 is not a new bug.

## Current limits

- The installer targets **64-bit Windows PCs**, not Mac or Linux. Other Windows device types have not been validated for this kit.
- The test installer is not signed, so Windows may show an unrecognized-app warning. Check with John if unsure; do not disable protection.
- Updates are manual. There is no built-in uninstaller yet; ask John for help removing the app and deciding whether to keep your saved data.
- Closing the dashboard tab leaves the background app running. The Desktop shortcut restarts it, so avoid using that shortcut during a stream.
- The guided demo uses made-up readings and does not test your actual internet quality or create a saved stream report. **Only the demo panel is simulated.**
- Twitch features need your approval and depend on what your channel can use. Twitch clips may need a live stream and clips enabled. Ads and rewards may not be available to every channel.
- Spotify is optional; playback controls need Spotify Premium and an available playback device. Skip it for the first test.
- Replay saves need the OBS Replay Buffer enabled and running. A highlight marker does not guarantee a video file was saved.
- World of Warcraft addon tools are currently paused and hidden by default, even if you select an RPG profile.
- Keyboard shortcuts work when the dashboard tab has focus, not while you are playing in another window.
- Connection settings and reports belong to this Windows account on this PC. They are not automatically shared with John or copied to another computer.

The [one-minute video](https://github.com/ReallyJohnSmith/johns-twitch-handler/raw/refs/heads/main/docs/media/Johns-Twitch-Handler-60-Second-Tour.mp4) shows the development preview, including features waiting for the next release. It is a separate download, not part of the installer. Setup and the first test do not depend on it.
